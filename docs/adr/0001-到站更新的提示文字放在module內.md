# 0001 到站更新的提示文字放在 module 內

## 背景

到站更新（`updater.js`）決定何時查到站、查完存什麼、看第幾段，再把純資料的畫面資料交給 `app.js` 畫出來。看板上的提示文字也在這個 module 裡，例如「約 N 秒後送出查詢…」「已暫停自動更新…」「這一段找不到路線…」。設定頁的排隊提示也共用 `Updater.waitText`。

程式審查用通用的壞味道基準時，會把這點標成「一個 module 因為多種理由被改」：一個說自己不碰畫面的 module，卻持有畫面文字。

## 決定

看板上的提示文字維持放在到站更新 module，以純文字交給 `app.js`，由 `app.js` 畫的時候統一跳脫。設定頁自己的文字不搬進來。

## 理由

- 哪種情況顯示哪句提示本身就是規則，例如額度限制時要多加「畫面是最後一次的資料。」。放在 module 裡就能直接用自動測試檢查，不必開瀏覽器。
- 如果改成交出代碼、再由 `app.js` 翻成文字，判斷規則和文字會分散在兩個檔案，改一句提示要對照兩邊。

## 後果

- 改看板提示文字時要改 `updater.js`，並更新它的版本號。
- 設定頁依賴 `Updater.waitText`；`app.js` 用 `const waitText=Updater.waitText` 取個短名字。
- 之後的架構檢視與程式審查，不再把這點列為要處理的問題。
